# Ecosoft CRM

Приватна CRM для замовлень, заявок і клієнтів магазину Sofiivka Water.

## Можливості

- автоматичний прийом замовлень, консультацій і зворотних дзвінків із сайту;
- захищені сесії та ролі користувачів;
- клієнти без дублів за нормалізованим номером телефону;
- товари, сума, спосіб і статус оплати без онлайн-еквайрингу;
- повна історія зміни статусів;
- видалення звернень і клієнтів доступне лише адміністратору та вимагає підтвердження;
- підбір обладнання за аналізом води й генерація PDF-КП вбудовані в основну CRM;
- UTM, Facebook/Google click IDs і сторінка входу;
- Meta CAPI `Lead` під час створення та `Purchase` лише після статусу `completed`;
- GA4 Measurement Protocol для серверних конверсій;
- автоматична щоденна SQLite-копія з ротацією за 14 днів;
- інші збережені робочі інструменти доступні за адресою `/tools`; підбір і КП звідти прибрані.

## Локальний запуск

1. Скопіюйте `.env.example` у `.env` та задайте унікальні секрети.
2. Встановіть залежності: `npm install`.
3. Запустіть: `node --env-file=.env server.mjs`.
4. Відкрийте `http://127.0.0.1:3100`.

Потрібен Node.js 20–24. Дані й завантаження не можна зберігати всередині каталогу релізу — для production використовуйте постійні шляхи через `CRM_DATABASE_PATH`, `CRM_UPLOAD_DIR` та `CRM_BACKUP_DIR`.

## Production

Сервіс слухає лише `127.0.0.1:3100`; зовнішній HTTPS завершує Nginx. Секрети зберігаються у `/etc/ecosoftcrm.env`, база — у `/var/lib/ecosoftcrm`, резервні копії — у `/var/backups/ecosoftcrm`.

Публічний intake endpoint:

```http
POST /api/v1/intake
Authorization: Bearer <CRM_INTAKE_TOKEN>
Content-Type: application/json
```

Повторний запит з тим самим `externalId` не створює дубль.
